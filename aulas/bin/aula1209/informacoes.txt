public static float "somar(float a, float b)"{ = a àrea marcada é chamada de assinatura "somar(float a, float b)"

se errar o tipo dos parametros da erro ja na compilação, é de suma importância enviar dados corretos à assinatura
ex: somar("abc" + 2);

se eu adiciono 10.2 em somar(10.2 + 2) gera erro, é necessário digitar 10.2f para dizer q um valor é float


somar(1,2,3) por que retornaria erro? r: porque a assinatura está errada!

assinatura = nome do método + tipo dos parâmetros


é possivel existir métodos com o mesmo nome na mesma classe! = SOBRECARGA
só posso ter sobrecarga(métodos de mesmo nome) se os métodos tiverem assinaturas diferentes
ex:
public static void somar(float a, float b){
public static void somar(float a, float b, float c){
public static void somar(int a, float b){
public static void somar(int a, int b){

ou seja SOBRECARGA são métodos com o mesmo nome, porém com assinaturas diferentes na mesma classe.

(float a, float b) = PARÂMETROS

um parâmetro é uma váriavel local, porque funciona apenas dentro do método.
tempo de vida: existe apenas durante a execução do método.



diferenças entre parâmetros e argumentos

parâmetros são as variaveis do método, argumentos são os dados colocados nos campos dos parametros ao chamar tal método 
ex: somar(5,2), 5 e 2 são os parâmetros


eu posso ter métodos abstract, final, syn... mas são incomuns


tudo que está dentro da chave -> {} é o corpo/implementação -> define o que o método faz
